ELIAS BABY WEBSITE
===================

This folder is ready for GitHub Pages.

Files:
- index.html
- style.css
- script.js
- assets/elias-lullaby.wav

How to publish:
1. Create a new GitHub repository.
2. Upload ALL files/folders from this folder.
3. Open Settings -> Pages.
4. Under Build and deployment choose "Deploy from a branch".
5. Select the main branch and the / (root) folder.
6. Save and wait for GitHub Pages to publish.

The website needs no image files. The teddy, clouds, balloons and stars are
drawn directly with CSS. The included lullaby is an original generated
instrumental file and is stored locally, so the music works from GitHub Pages.
